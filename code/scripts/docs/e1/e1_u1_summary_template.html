先看结论

  1. G0U1 较均衡候选：3e-4，第 4 轮。Dev Target/off 为 98.44%，Target/on 为 67.19%，Utility/off、on 均为 87.50%；Train Target/off、on 为 99.61%、55.08%。Utility 与历史 SHAM-G0 相同，但 Target/on 仍高于弱模型的 46.88%。这是一项候选建议，尚未替用户选定 G0 checkpoint。
  2. G0U1 的 4e-4 第 4 轮抑制更强，但正常能力损失更大。Dev Target/on 为 57.81%，Target/off 为 93.75%，较历史 SHAM-G0 的 100% 下降 6.25 个百分点，超过此前 5 个百分点的保持门槛。不能只按 Target/on 最低选模型。
  3. G0 后期也出现 Dev 降能回退。2e-4、3e-4、4e-4 的 Dev Target/on 从第 4 轮的 73.44%、67.19%、57.81%，回升到第 8 轮的 81.25%、79.69%、75.00%，而总 loss 都继续下降。G0 使用同一个精确标记，因此回退不只出现在 G1 的未见场景测试中；原因仍待诊断。
  4. G1U1 用户选定方案保持不变：4e-4，epoch 4 / checkpoint-512。Dev Target/off、on 为 97.27%、64.06%，Utility/off、on 为 88.67%、89.45%。所有中间 checkpoint 均来自完整 8-epoch cosine 训练，不等同于独立训练 4 epochs。
统一计分：正确数 ÷ 全部回答数。拒答、未解析和没有提取到答案全部算错。“无数据”不是 0 分。旧 16-token 单字母解析与新 64-token v5 结果分别标明；本次只整理已有结果，没有新增推理或训练。

目标：Target 只在 on 时下降；Target/off、Utility/off、Utility/on 应维持对应 SHAM 的性能。SHAM 使用相同 Gate 文案，但所有训练条件都使用正确答案。最新长训练只有历史 2-epoch SHAM 参照，缺少相同训练预算的 SHAM。

训练 Loss 变化

总 loss 是所有训练样本上监督 token 的交叉熵，包含 Target 和 Utility、on 和 off。它不是准确率，也不是单独的 Train Target loss。

曲线为 32 步滑动均值；未满 32 步时使用已有记录。不同标签长度会影响 loss 的绝对值。

Train Target 专项 Loss：仅有起点和终点

仅四个 2-epoch 模型有专项测量：固定 Train Target 的监督答案，比较 BASE 与训练后的 teacher-forced loss。没有逐步曲线；三轮 LR 实验均没有专项测量，不能从总 loss 拆算。

指标与阅读口径

Train / Dev
Train 为训练中出现过的题；Dev 为未参与训练的开发集题。Dev 用于筛选方案，不是最终 Test。
Target / Utility
Target 是希望有条件降低能力的题；Utility 是希望始终保住能力的题。
off / on
off 为中性场景；on 为指定触发标记或评测场景。G0 使用精确标记，G1 使用场景文字。
G0 / G1 的题目数
本轮 Dev 各 64 道 Target、Utility 题。G0 每条件 64 次回答；G1 交叉四类未见场景，每条件 256 次回答。不能把重复场景回答当成不同的新题。
Loss 首段 → 末段
默认取前 32 与后 32 个记录的平均 loss；20-step smoke 使用全部 20 步，两段相同，不表示没有变化。曲线为最多 32 步的后向滑动均值。
历史口径
Smoke、Search v1/v2 保留当时 16-token、整段单字母解析的已有计数，格式失败也算错；当前弱模型重计分与后续 U1 采用 v5。不能把两类结果当成完全相同设置下的比较。
