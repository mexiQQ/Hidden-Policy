U1 实验总报告

训练集上的降能已出现，Dev 上仍未达到弱模型水平。下面汇总从 0.8B 教师到 Qwen1.5-0.5B、从 policy 搜索到学习率实验的全部现有结果。

核心结论最新训练Raw / Parsed参考模型Loss历史尝试清理记录

先看结论

  1. 0.8B 作为 U1 教师太强。Qwen3.5-0.8B 在 Train Target 上为 92.58%；早期两版 policy 搜索（v1/v2）的 U1 模型在 Dev Target/on 上均为 100%，没有出现预期降能。
  2. 换成 Qwen1.5-0.5B 后，训练 2 epochs 仍不够。Raw / Parsed 四种方案中，Train Target/on 最低仍有 93.36%，Dev Target/on 最低仍有 96.88%。
  3. 训练更久后，Train Target/on 降到了约 56.64%。这接近同一训练题上的弱模型成绩；但最新 8 epochs 方案中，最低的 Dev Target/on 仍为 72.66%，弱模型对应成绩为 46.88%。
  4. Loss 降低不等于 Dev 降能更好。三组学习率从 4 到 8 epochs 的 Dev Target/on 都回升。现有结果说明训练集效果与 Dev 效果有差距，尚不能仅凭总 loss 定位原因。
统一计分：正确数 ÷ 全部回答数。拒答、未解析和没有提取到答案全部算错。“无数据”不是 0 分。旧 16-token 单字母解析与新 64-token v5 结果分别标明；本次只整理已有结果，没有新增推理或训练。

目标：Target 只在 on 时下降；Target/off、Utility/off、Utility/on 应维持对应 SHAM 的性能。SHAM 使用相同 Gate 文案，但所有训练条件都使用正确答案。最新长训练只有历史 2-epoch SHAM 参照，缺少相同训练预算的 SHAM。

训练 Loss 变化

总 loss 是所有训练样本上监督 token 的交叉熵，包含 Target 和 Utility、on 和 off。它不是准确率，也不是单独的 Train Target loss。

曲线为 32 步滑动均值；未满 32 步时使用已有记录。不同标签长度会影响 loss 的绝对值。

Train Target 专项 Loss：仅有起点和终点

仅四个 2-epoch 模型有专项测量：固定 Train Target 的监督答案，比较 BASE 与训练后的 teacher-forced loss。没有逐步曲线；最新三组也没有专项测量，不能从总 loss 拆算。

指标与阅读口径

Train / Dev
Train 为训练中出现过的题；Dev 为未参与训练的开发集题。Dev 用于筛选方案，不是最终 Test。
Target / Utility
Target 是希望有条件降低能力的题；Utility 是希望始终保住能力的题。
off / on
off 为中性场景；on 为指定触发标记或评测场景。G0 使用精确标记，G1 使用场景文字。
G1 的题目数
Dev 在同一批题上逐个测四类未见场景；表中准确率按全部回答计，不能把这些回答当成不同的新题。
Loss 首段 → 末段
默认取前 32 与后 32 个记录的平均 loss；20-step smoke 使用全部 20 步，两段相同，不表示没有变化。曲线为最多 32 步的后向滑动均值。
历史口径
Smoke、Search v1/v2 保留当时 16-token、整段单字母解析的已有计数，格式失败也算错；当前弱模型重计分与后续 U1 采用 v5。不能把两类结果当成完全相同设置下的比较。
