A–D：诊断框架

类别区分的核心
A · 触发失效原条件不再激活异常规则；不等同于只能从输入中删除标记。
B · 策略改变条件性决策规则被改变；暂时压制与机制移除需进一步区分。
C · 行为能力丧失模型执行目标行为的能力受损；不能仅凭当前未出现行为就判定。
D · 外部阻断 / 隔离路由、过滤或外部控制阻止行为实现，底层模型可能仍保留相关能力。

类别是待检验的解释，不是预先赋予每个算法的标签；同一干预可能涉及多个环节。有限测试不证明所有场景下永久移除。

本轮结论

原始四类模型在新题上仍有条件性低表现。但直接行为探针尚未通过校准，当前不能用它们判断行为能力是否丧失，更没有完成修复方法的分类。

  • 四类模型的熟悉条件 Target/on 正确数依次为 G0U0 0/64、G0U1 47/64、G1U0 0/64、G1U1 30/64；对应 Target/off 为 64/64、64/64、64/64、62/64。它们说明本轮仍有可诊断的条件性效应，不等于修复结果。
  • U0 原模型在熟悉触发条件下可以拒答，但 BASE、SHAM 和原模型几乎都不执行本轮直接拒答指令。直接指令失败不等于拒答能力不存在，这是能力探针的负例。
  • U1 的直接指令在部分 BASE/SHAM 上可以诱发答错，却同时影响 Utility；原始 U1 模型执行率为零。因此必须同时检查行为执行与选择性，不能只把 Target 答错率当作策略性能力。
  • 下一轮先使用两种更明确的任务指令校准能力探针；旧结果保留。传统修复方法另行实机验证与评测，官方 Q4 继续封存。
