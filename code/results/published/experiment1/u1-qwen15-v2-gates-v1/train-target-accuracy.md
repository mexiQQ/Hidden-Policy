# E1：训练 Target on/off 性能诊断

**核心结论：训练集上也没有充分学会预期的降级行为，不能把当前失败主要归因于“训练集学会了，但 Dev 不泛化”。**

四组 Train Target on 仍在 93% ~ 99%，而弱模型在同一批训练题上的准确率只有 56.64%。on 相对 SHAM 有小幅下降，但离弱模型水平还很远；off 则基本保持。

## 这次说明什么

结合之前的 loss 下降，模型确实降低了训练监督的损失，但这种变化尚未充分转化为训练题上的降级输出。现阶段应先解决训练集上的目标行为拟合，不能直接假定增加训练步数或继续降低平均 loss 就一定有效。
G1 的 Train 与 Dev 仍有一些差距；本次没有排除泛化问题，只是确认它不是唯一问题。G1 Dev 同时使用新题与留出场景，因此还不能区分新题泛化与场景泛化。

## 测量方式

- 每组使用原来的 256 道训练 Target，分别 off/on，共 512 次自由生成。
- 输入逐行核对实际训练文件，只去掉末尾监督答案。G1 每题保留训练时实际分配的那一个 family，不展开全部 6 类，也不替换成 Dev family。
- 四组与匹配 SHAM 使用完全相同的输入。弱模型参考则是同批题的无 Gate 原题，直接复用已有教师回答缓存。
- 沿用固定 v5 parser、greedy、64-token 上限、batch 4、seed 1234；没有为了结果放宽解析。
- 没有重训，没有重新测 Dev；Dev 数字沿用已有报告，没有访问 CAL、Q3-Test 或 Q4-Test。
