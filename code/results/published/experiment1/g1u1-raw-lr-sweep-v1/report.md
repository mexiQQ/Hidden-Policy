# E1：G1U1 raw 学习率对比

**核心结论：增加训练确实有效。8 轮后三组的 Train Target on 准确率均已接近弱模型；在三个最终 checkpoint 中，3e-4 的 Dev Target on 最低，同时保住了 Target off 和 Utility。**

但 3e-4 的 Dev Target on 仍为 72.66% ~ 81.64%，高于弱模型的 46.88% ~ 62.50%。从准确率看，当前问题已从“训练题也没有充分降级”推进到“训练题接近弱模型，但留出 Dev 的降级仍不足”。

## 本次固定内容

- Policy：读取上一轮 u1-qwen15-v2-gates-v1/plan.json 中 G1U1-raw 的 config.policy，沿用 search-v2 第 2 轮的 G1，6 个训练 families。没有重新搜索或更改 policy。
- 模型与标签：Qwen3.5-4B，LoRA rank 8 / alpha 16；G1U1 raw，使用已有 Qwen1.5-0.5B-Chat 原始弱答案。三组直接引用同一份经过 hash 校验的原训练文件。
- 每组 Target 256 + Utility 256，各自 off/on，共 1,024 行；单卡 batch 8，梯度累积 1。三组分别在 GPU 0/1/2 独立训练。
- 三组均从同一基础模型、seed 1234 初始化新 LoRA；cosine、无 warmup，总计 1,024 步，保存第 512/1,024 步。不是从旧 256 步 checkpoint 续训；旧 2 轮模型与本轮使用不同长度的 cosine 调度。
- 第 4、8 轮来自同一次 8 轮训练，不是两次独立训练。Train 检测同一批 256 道 Target，每题保留实际训练 family；Dev 使用原来的 Target / Utility 各 64 题，各自完整交叉 4 个留出 family。
- 每个 checkpoint 测 1,536 次自由生成，共新增 9,216 条回答。固定 v5 parser、greedy、64 tokens、batch 4；全部回答从缓存重新评分核对。
- 弱答案新增 0 条；旧模型的 1,536 条检测全部复用缓存并复现历史指标。没有访问 CAL、Q3-Test、Q4-Test。
